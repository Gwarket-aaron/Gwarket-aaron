# Building practical AI workflows and tools

I turn ambiguous work into small, inspectable systems with explicit inputs, human approval, verifiable outputs, and honest boundaries.

| Project | What it demonstrates |

## Working principles

- Make the first useful result small enough to inspect.
- Keep facts, decisions, permissions, and human approval visible.
- Prefer local-first and reversible workflows when private material is involved.
- Separate implementation readiness from real-world validation.
- Ship documentation, tests, privacy boundaries, and explicit limitations with the artifact.

Each public project includes a stable release, automated package validation, and documented evidence boundaries.
